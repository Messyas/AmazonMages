# Capturas do renderer Android

Imagens geradas pelo teste instrumentado `WorldStreamingTest`, usando `GameRenderer`, sprites reais e Canvas Android de 1280 × 720. O HUD e o loop de combate não fazem parte destas capturas.

| Arquivo | Conteúdo |
|---|---|
| `center.png` | Spawn central e árvores de enquadramento |
| `castanheira.png` | Corredor entre raízes colossais, junto à base |
| `malocas.png` | Frente da maloca norte |
| `ancient.png` | Base do templo escalonado |
| `burned.png` | Solo queimado e base da árvore morta |
| `modern.png` | Fachada do teatro |
| `negro.png` | Margem escura e aproximação da ponte |
| `meeting.png` | Ponte entre as duas faixas do Encontro das Águas |
| `port.png` | Extremidade do cais no canal da cidade |
| `forest.png` | Floresta viva, profundidade e transparência sobre o jogador |
| `north_crossing.png` | Travessia norte do Negro |
| `west_bank.png` | Trilha na margem oeste |
| `arena_*.png` | Centro livre de cada uma das quatro arenas futuras |

Construções monumentais aparecem parcialmente na câmera normal; a visão de conjunto está no [overview real](../../../art/world-v1/world_runtime_overview.png). As arenas têm piso livre maior que uma tela; vistas do centro mostram a área de combate, sem bosses implementados.

O JSON `renderer-report.json` registra as coordenadas efetivamente validadas e as medidas do teste prolongado. Resultados e limitações: [relatório](../2026-10-27-world.md).
